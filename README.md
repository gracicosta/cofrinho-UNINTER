# 💰 Cofrinho em Java

Sistema de cofrinho desenvolvido em Java que permite adicionar, remover e listar moedas de diferentes tipos, além de realizar a conversão do valor total para reais.

## 🚀 Funcionalidades

- ➕ Adicionar moedas (Real, Euro, Dólar)
- ➖ Remover moedas
- 📋 Listar moedas armazenadas
- 💱 Converter o total para reais
- 🧠 Uso de herança e polimorfismo

## 🛠️ Tecnologias utilizadas

- Java
- Programação Orientada a Objetos (POO)

## 📂 Estrutura do projeto

- Cofrinho.java → Gerencia as operações do cofrinho
- Moeda.java → Classe abstrata base
- Real.java → Representa moeda em Real
- Euro.java → Representa moeda em Euro
- Dolar.java → Representa moeda em Dólar
- index.java → Classe principal com menu interativo

## 💡 Conceitos aplicados

- Herança
- Polimorfismo
- Encapsulamento
- Classes abstratas
- Estruturas de repetição
- Manipulação de listas (ArrayList)
